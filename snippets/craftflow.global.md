# CraftFlow architecture guidance

When module boundaries, dependency direction, state ownership, or contracts need attention, choose the CraftFlow skill for the requested outcome: `craftflow-set` for investigation, design, or review, and `craftflow-go` for authorized changes. Consult architecture references only to resolve a relevant decision; a local formatting edit needs no separate architecture pass.

Resolve the skill through the location advertised by the host, including any plugin prefix. If unavailable, use project evidence and report material limits. Planning and review preserve the assessed material; reading implementation references does not authorize edits. Do not require a Set/Go sequence.
