## 아키텍처 유지보수

코드·설정·의존성 변경을 시작하기 전과 완료를 보고하기 전에
`architecture-guard` 스킬로 변경 범위의 설계와 최종 변경을 점검한다.
스킬이 자동 선택되지 않으면 설치된 `architecture-guard/SKILL.md`를 직접 읽는다.
프로젝트 설치 경로는 `.agents/skills/architecture-guard/SKILL.md`다.

점검은 작업 단위로 수행하며 파일을 저장할 때마다 반복하지 않는다.
순수 문구·서식 변경은 아키텍처 영향이 없는지만 확인하고 깊은 검토는 생략한다.
관련 경계·호출부·계약을 우선 보고, 근거 없이 전체 저장소 감사로 확대하지 않는다.
리뷰·계획만 요청받았다면 소스·설정·문서를 수정하지 않는다.
완료 시 검토 범위, 중요한 문제, 검증 결과와 미확인 사항을 간단히 보고한다.
