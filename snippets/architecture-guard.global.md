## 아키텍처 유지보수

코드·설정·의존성을 변경하기 전과 완료를 보고하기 전에
`architecture-guard` 스킬로 관련 설계와 최종 변경을 점검한다.
자동 선택되지 않으면 개인 설치 경로 `~/.agents/skills/architecture-guard/SKILL.md`를 읽는다.

점검은 작업 단위로 수행하고 파일 저장마다 반복하지 않는다.
순수 문구·서식 변경은 아키텍처 영향이 없는지만 확인한다.
관련 경계·호출부·계약에서 시작하고 근거 없이 전역 감사나 전체 재설계로 확대하지 않는다.
계획·리뷰만 요청받았으면 소스·설정·문서를 수정하지 않는다.
완료 시 검토 범위, 중요한 문제, 실행한 검증과 미확인 사항을 간단히 보고한다.
