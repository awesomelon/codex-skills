## 유지한 내용

세 스킬의 역할, 읽기 전용 요청, 사용자 요구에 따른 구현·검증 완료, 실제 근거에 따른 결론을 유지했다. 아키텍처의 소비자·상태·의존 판단과 React의 draft 보존·요청 순서·캐시 격리·버전별 API 조건도 유지했다. 전문 참조를 길다는 이유로 줄이지 않았다.

`agents/openai.yaml`의 표시·호출 예시·자동 선택 설정은 적절해 변경하지 않았다. 저장소 AGENTS.md는 관련 문서·검증을 조건별로 선택하고 원격 작업 범위를 제한하고 있어 유지했다. 최초 게시 템플릿은 명시적 최초 게시 요청용이고 실제 계정·원격 확인이 필요한 절차이므로 유지했다. 설치기·검사기는 변경하지 않았다.

점수와 원문 수식은 기존 내용을 새 참조로 옮겼다. React 원문이나 지표 원문의 새 버전으로 갱신한 작업은 아니며, 원문의 수치 효과를 새로 검증했다고 주장하지 않는다.

## 검증 결과와 한계

- 저장소 `scripts/validate.py`: 세 스킬의 구조·메타데이터·내부 참조 통과.
- 공식 `quick_validate.py`: 세 스킬 통과. UI YAML과 명시 호출 예시·자동 선택 설정도 확인했다. PyYAML 6.0.3은 일회용 가상환경에서 사용했다.
- macOS 임시 폴더의 복사 설치: 세 스킬 전체가 설치됐고 새 scoring.md를 포함한 원본 파일의 내용이 모두 같았다. 실제 개인 설치 폴더는 사용하지 않았다.
- 구현 평가: 품질 테스트 7개 전후 통과, React 실제 계산식 검사 통과, 음량 범위 테스트 통과. 모든 실행의 TASK·제공 테스트·스킬 사본은 해시가 같았다.
- 저장한 수정 patch의 재적용과 최종 소스 해시, 문서 링크·공백을 확인했다. AGENTS.md는 감사 전 사본과 직접 비교해 동일했다.

설치기·검사기를 변경하지 않아 해당 전체 테스트를 반복하지 않았다. React 렌더·브라우저 상호작용·타입·빌드·성능은 입력에 실행 환경이 없어 미검증이다. 점수·A/B·원문 지표의 실제 계산, 스킬 미발견, 공개 API 변경 시 자동 호출, 다양한 모델·대규모 저장소·데스크톱 앱의 자동 선택은 이번 실행 범위에 없다. 새 평가 시나리오 전체가 통과했다고 주장하지 않는다.

감사는 `feature/skill-audit-2026-09-14` 브랜치에서 수행했다. 평가 과정에서 설치된 스킬·전역 지침·현재 앱 프로젝트는 변경하지 않았다. 원격 반영은 감사 완료 이후 별도 요청에 따라 진행한다.
