## 문서 분량

Python `len(text)`로 공백·개행을 포함해 센 문자 수다. 참조 수치는 SKILL.md를 제외한 해당 경로의 문서 합계이며 실제 토큰 사용량이나 속도가 아니다. 기존 scoring.md는 measurement.md를 공통 조건으로 연결하므로 이전 합계에 둘을 포함한다.

| 읽기 대상 | 이전 | 이후 |
| --- | ---: | ---: |
| 새 스킬 요청 템플릿 전체 | 1,239 | 794 |
| 현재 상태의 정성 점수 참조 | 2,709 | 366 |
| 점수 없는 A/B 비교 참조 | 2,709 | 1,728 |

일반 전후 비교용 measurement.md는 A/B 판단 문단 이동으로 1,563→1,728자가 됐다. 특수 지표가 필요한 요청은 해당 문서와 공통 측정 조건을 함께 읽는다. 모든 경로의 길이를 줄이기 위한 변경은 아니다.

## 검증

- 저장소 `python3 scripts/validate.py`: 세 스킬의 구조·내부 참조 통과.
- 공식 `quick_validate.py`: 세 스킬 통과. UI YAML의 설명 길이·명시 호출 예시와 기존 선택 정책도 확인했다.
- Linux 임시 폴더에서 `bash scripts/install.sh --mode copy --dest <임시경로>` 실행: 새 참조를 포함한 원본 15개 파일과 설치본의 내용이 일치했다. macOS 실기 검증은 아니다.
- 점수 없는 A/B 비교를 새 대화의 독립 평가 한 번으로 실행했다. 기존 보관 정책 fixture와 기존 개선 patch로 두 사본을 준비하고 스킬·제품 계약·사용자 요청만 전달했다. 평가 응답은 measurement.md 사용, 두 구현 각각 기존 테스트 7개 통과, 독립 핀 정책 보존을 보고했다. 입력 전체 15개 파일의 전후 해시 일치는 별도로 확인했다. [실제 응답](../evals/code-quality-guard/outputs/ab-routing-review.md)과 [요청·해시·검증 기록](../evals/code-quality-guard/outputs/ab-routing-manifest.json)을 보존했다. 참조 사용과 테스트 결과는 평가 응답에 근거하며 원시 도구 실행 추적은 별도로 저장하지 않았다.

점수 요청·특수 지표 계산·UI 기본 프롬프트의 새 행동은 정적 검토와 평가 시나리오 갱신 범위다. 설치기·검사기는 변경하지 않아 전체 설치 테스트를 반복하지 않았다. 실제 데스크톱 자동 선택, 여러 모델·반복 실행의 안정성, 응답 시간·토큰 절감은 별도로 측정하지 않았다.
