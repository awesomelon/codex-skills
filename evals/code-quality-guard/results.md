## 패키지 검증

- `python3 scripts/validate.py`: 세 스킬의 메타데이터·설치 가능 내용·내부 참조 통과.
- `quick_validate.py skills/code-quality-guard`: 스킬 기본 검증 통과.
- `bash scripts/install.sh --list`: 새 스킬 발견.
- 임시 대상에 새 스킬만 link/copy 설치 후 각각 재실행: 설치·멱등성·모든 파일의 내용 보존 확인.
- `node --test evals/code-quality-guard/fixtures/policy/policy.test.mjs`: 원본 fixture 7/7 통과.
- `git diff --check`: 공백 오류 없음.

설치기·검사기는 수정하지 않았다. 실제 홈이나 Codex 설정을 테스트 대상으로 사용하지 않았다.

## 제한

사례 4–10, 기존 아키텍처·React 스킬과의 결합 호출, 자동 선택, macOS 실기, 다른 언어·대규모 저장소는 실행하지 않았다. 명시적으로 주입한 두 사례의 성공으로 일반적인 품질 향상이나 자동 호출 정확도를 보증하지 않는다. AST/clone 분석기 및 원문 Verbosity/Erosion 계산도 실행하지 않았다. 이 스킬은 품질 검사의 판단 절차이며 강제 CI 게이트나 자동 채점기를 설치하지 않는다.
