# 요청

React 화면의 코드 품질을 리뷰만 해줘. 소스나 설정 파일은 수정하지 마. 중요한 문제와 최소 조치, 검증 한계를 한국어로 알려줘.

앱은 Vite SPA이고 React Compiler는 사용하지 않는다. 동일한 QueryClient를 유지한 채 tenantId를 전환할 수 있다. API는 요청한 테넌트의 데이터만 반환한다. 서버에서 같은 문서 데이터가 재조회되어도 사용자가 편집 중인 제목은 저장 전까지 유지해야 한다. 저장 중 버튼 비활성화와 실패 알림은 기존 동작이다.

이 폴더는 전체 평가 입력이다. 잠금 파일·실행 의존성·프로파일·이전 커밋은 제공하지 않는다. 네트워크 접속이나 패키지 설치 없이 제공한 코드로 검토하고, 확인할 수 없는 결과는 구분해줘.
