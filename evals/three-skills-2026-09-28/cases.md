# Three task-oriented skills

These are expected behaviors, not execution results. Explicit invocations select a task endpoint; technical topics select references within that endpoint.

## Plan

- Assess a proposed shared disk cache for repeat-query latency and offline export. Separate evidence from hypotheses, compare alternatives, identify unresolved policy, and propose a useful next check without files or implementation.
- For a clear local implementation request, do not make prior planning or a new specification a prerequisite. A requested plan may be a short answer.

## Build

- Simplify repeated receipt construction with a single behavior owner. Preserve public API, values, error identity, effect order, and existing test assertions; implement and verify without invoking another skill.
- Resume dependent work using current files and evidence. Reconcile stale checkpoints; optional delegation does not create authority for external actions.
- For React, Query, TypeScript, architecture, and refactoring work, select only relevant technical references. Topic names are not additional installed skills.

## Review

- Assess migration completeness from source and stale checkpoint notes. Check the producer/consumer contract, distinguish stale verification and historical worker status, and preserve every input file.
- Review a React/Query change using optional build references when present. Reading implementation guidance must not switch the task into implementation.
- Operate without other installed skills. Missing optional references do not block source-grounded review or justify invented findings.

## Packaging and discovery

- Plugin and standalone discovery expose exactly plan, build, and review; each folder has portable local references. No old skill aliases are installed.
- Installation migration explains how to preserve edits and remove superseded discovery entries.
- Test automatic selection separately with unnamed planning, implementation, and review requests in a real host. Explicit-invocation smoke cases do not establish automatic discovery.
