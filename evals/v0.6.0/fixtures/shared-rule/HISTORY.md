# Plan ownership

The catalog owns billing quotas and public plan labels. Billing and display are consumers of that same catalog policy. Unknown plans return 0 quota and "Unknown" label. Public function names remain stable.

Two prior plan launches required follow-up fixes because catalog changes were not copied into billing and display. Another written reminder did not prevent the Team launch from repeating the mistake. Future catalog additions must become available through both consumers without synchronized edits. This is one policy, not consumer-specific overrides.
